# 本地 MDX 点击查词 0.1.0

为 Zotero 10.0 系列制作的本地词典插件。在 PDF 正文中单击英文单词，就在鼠标附近显示所选 MDX 词典的释义和例句。

从 [GitHub Releases](https://github.com/Noahxie83/zotero-local-mdx-click/releases) 下载 `.xpi` 安装包。0.1.0 是首次公开预览版，目前实际验证的平台为 Windows + Zotero 10.0.3；其他系统尚未实际验证。

## 安装和使用

1. 打开 Zotero 的“工具 → 插件”，点击齿轮，选择“Install Add-on From File / 从文件安装插件”，选择 `local-mdx-click-0.1.0.xpi`。
2. 打开“设置 → 本地 MDX 点击查词”，点击“选择词典文件夹”，选择你保存词典的任意文件夹。也可以通过“选择 MDX 文件”直接选中某个词典，插件会一并列出它同目录的其他词典。
3. 插件列出文件夹当前层的全部 `.mdx` 文件，默认优先选择名称含“牛津”或“Oxford”的词典。可通过下拉框改选。
4. 打开有文字层的 PDF，在正文中单击英文单词即可查询。拖动选中、高亮工具和带 Ctrl/Alt/Shift 的点击不会触发。
5. 查词弹窗和 PDF 工具栏都有词典下拉框；在弹窗中切换会重新查询当前单词。选择会保存，重启后仍使用它。

增加、删除或替换词典文件后，在设置中点击“刷新词典列表”。首版只扫描所选文件夹当前层；子文件夹需要单独选择。词典留在原位置，不会复制进 Zotero 文献库。

点击 PDF 工具栏的“本地词典”按钮可以开关点击查询；右键点击按钮可以重新选择文件夹。安装时已打开的 PDF 若没有工具栏按钮，可关闭该标签再打开。弹窗可用右上角 ×、Esc、点击外部或滚动页面关闭。

如原来的 Hover Translate Eudic 也启用了点击取词，请在它的设置中关闭该触发方式，避免重复弹窗。

## 已支持和当前范围

- MDX 1.x、2.x；raw、zlib、LZO 压缩；支持 MDX 2 的 `Encrypted=2` 词目索引混淆格式。
- UTF-8、UTF-16、GBK 等浏览器支持的文本编码。
- 忽略大小写的查询（遵照词典配置）、词典内部 `@@@LINK` 跳转、跨数据块的词条。
- 在内存中保存当前词典的词目索引，释义按需读取，释义块缓存最多约 8 MB。只索引当前选中的一部词典。
- 词典 HTML 转成文字排版；不执行词典脚本，不访问翻译接口，不加载词条中的外部资源。

暂不支持 MDD 中的音频/图片、MDX 3、需要密码的词典、词典自定义脚本交互和 StyleSheet 反引号宏。首版不自动进行词形还原；若词典自身收录了变形或跳转词目则可查到。无文字层的扫描 PDF 无法直接取词，需要先有 OCR 文字层。跨行断词暂不自动拼接。

每个数据块最大 128 MB、单个词条最大 16 MB，显示的 HTML 最大 4 MB。损坏文件或不支持的词典会在界面显示原因。TLD 的词目数量较多，首次建立索引会比牛津词典更慢；切换词典时需要重新建立索引。

## 开发

源代码包含在此目录及配套源码 ZIP。需要 Node.js：

```powershell
npm ci --ignore-scripts
npm test
npm run build
```

构建生成 `addon/content/plugin.js`、`dist/` 中的 XPI 和校验文件。运行时不需要 Node.js 或 Python。

- `src/mdx.js`：本地词典索引、解压和查询。
- `src/word-at-point.js`：PDF 点击位置对应的单词。
- `src/render.js`：安全的词条排版及弹窗。
- `src/main.js`：词典文件夹、选择界面和 Zotero 生命周期。
- `addon/`：插件入口和设置页。
- `scripts/build.mjs`：构建和打包。

插件采用 GPL-3.0-or-later；第三方许可见 `THIRD_PARTY.md`、`src/vendor/NOTICE.md` 和 `addon/licenses/`。安装包和源码包不含任何词典数据。

## 验证记录

在独立的 Zotero 10.0.3 配置与文献库中进行了自动化运行检查：导入两部词典、从 PDF 点击 `research`、显示中文释义、在弹窗中切换词典并重新查询、保存选择、切回另一部词典、Esc 关闭，以及停用后移除点击监听。测试没有使用个人文献库。

另有使用原创小词典数据的自动化测试，覆盖 MDX 1.2/2、raw/zlib、Unicode、跨块末词、大小写、别名、跳转循环和损坏数据。多平台、扫描 PDF 的 OCR、其他插件共同启用时的完整交互仍需后续用户反馈。
