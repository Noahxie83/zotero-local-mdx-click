# 各版本发布记录

本页记录各版本的发布内容。1.1.3 为最新稳定版，新增插件图标，功能沿用 1.1.2。历史版本保留各自源码快照、标签、安装包、校验和与说明，验证记录对应其当时版本。

| 版本 | 内容 | 当前状态 |
| --- | --- | --- |
| 0.1.0 | 本地 MDX 点击查词、词典目录与切换 | 已有 GitHub Release |
| 0.1.1 | 文字排版与音标颜色 | GitHub 历史 Release，本地资产保留 |
| 0.1.2 | 词性导航、参照项、动词变形排版 | GitHub 历史 Release，本地资产保留 |
| 0.2.0 | 通用 MDD 分卷、原有 CSS、图片、字体与音频流程 | GitHub 历史 Release，本地资产保留 |
| 0.2.1 | 重复义项序号、备用字体提示、音频格式提示 | GitHub 历史 Release，本地资产保留 |
| 1.0.0（1.0） | 划选单词/词组、连字符与断行候选查询 | GitHub 历史 Release，本地资产保留 |
| 1.1.0（1.1） | 合并查词与批注菜单、8 色/高亮/下划线、内置 Speex | GitHub 历史 Release，本地资产保留 |
| 1.1.1 | 批注跨窗口数据传递修复 | GitHub 历史 Release，本地资产保留 |
| 1.1.2 | 审查整改、资源缓存与回归测试 | 稳定 Release，单一内置解码器版本 |
| 1.1.3 | 书本与放大镜 SVG 图标 | 最新稳定 Release，单一内置解码器版本 |

发布规则：

1. 依据各版已保留源码快照同步版本记录和标签，不用最终版源码冒充历史版本。
2. 为各版本上传对应安装包、源码 ZIP、校验和及说明，保留已有 0.1.0。
3. 稳定版使用与安装包一致的版本标签，并设为最新版本；每版提供一个内置解码器的安装包。
4. 先上传并发布安装包，再将 main 的 `updates.json` 更新到存在且校验匹配的安装包地址。

发布资产不包含用户词典、MDD、字体、音频或从用户词典生成的排版预览。运行时通过设置自行选择词典及资源目录。
