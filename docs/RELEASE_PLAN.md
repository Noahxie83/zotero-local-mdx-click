# 各版本发布记录

发布规则：

1. 依据各版已保留源码快照同步版本记录和标签，不用最终版源码冒充历史版本。
2. 为各版本上传对应安装包、源码 ZIP、校验和及说明，保留已有 0.1.0。
3. 最终版本使用 v1.1.2 标签及“1.1.2”发布标题，并设为最新版本，只有一个安装包。
4. 先上传并发布安装包，再将 main 的 `updates.json` 更新到存在且校验匹配的 1.1.2 安装包地址。

发布资产不包含用户词典、MDD、字体、音频或从用户词典生成的排版预览。本地文件位于用户指定的 `D:\Project`，插件运行和其他使用者不依赖此路径。
