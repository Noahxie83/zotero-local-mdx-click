# 各版本发布计划

当前发布状态：只有 v0.1.0 已公开。按照用户要求，等待用户检查 1.1.1 并确认无问题，再上传其他版本。当前不修改远程仓库、Release 或更新地址。

| 版本 | 内容 | 当前状态 |
| --- | --- | --- |
| 0.1.0 | 本地 MDX 点击查词、词典目录与切换 | 已有 GitHub Release |
| 0.1.1 | 文字排版与音标颜色 | 本地 XPI、源码 ZIP、说明 |
| 0.1.2 | 词性导航、参照项、动词变形排版 | 本地 XPI、源码 ZIP、说明 |
| 0.2.0 | 通用 MDD 分卷、原有 CSS、图片、字体与音频流程 | 本地 XPI、源码 ZIP、说明 |
| 0.2.1 | 重复义项序号、备用字体提示、音频格式提示 | 本地 XPI、源码 ZIP、说明 |
| 1.0.0（1.0） | 划选单词/词组、连字符与断行候选查询 | 本地 XPI、源码 ZIP、说明 |
| 1.1.0（1.1） | 合并查词与批注菜单、8 色/高亮/下划线、内置 Speex | 本地历史 XPI、源码 ZIP、说明 |
| 1.1.1 | 批注保存数据通过阅读器窗口复制，校验颜色/位置/排序字段 | 单一带解码器版本，本地 XPI、源码 ZIP、说明，待用户检查 |

用户确认后：

1. 依据各版已保留源码快照同步版本记录和标签，不用最终版源码冒充历史版本。
2. 为各版本上传对应安装包、源码 ZIP、校验和及说明，保留已有 0.1.0。
3. 最终版本使用 v1.1.1 标签及“1.1.1”发布标题，并设为最新版本，不建立完整/精简两个分支或安装包。
4. 更新 `updates.json` 到已发布且存在的 1.1.1 安装包地址。

发布资产不包含用户词典、MDD、字体、音频或从用户词典生成的排版预览。本地文件位于用户指定的 `D:\Project`，插件运行和其他使用者不依赖此路径。
