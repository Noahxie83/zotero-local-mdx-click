# 划选查询与批注菜单实现（1.1）

## 读取选区

`src/selection-query.js` 优先读取 Zotero PDF view 的 `_selectionRanges`。依据 `position.pageIndex` 与 `anchorOffset` / `headOffset`，只读取当前选区在 `_pdfPages[].chars` 中的字形，不重新解析全文或修改阅读器选区。反向拖选按阅读顺序处理。

字形的 `lineBreakAfter`、`paragraphBreakAfter` 和 `spaceAfter` 用于恢复分隔。被标记 `ignorable` 的词内连字符仍保留为候选。语义选区可能略过另一栏文字，因此只有去标点后的字形内容与选区文本一致，才用字形重建文本；否则使用阅读器自己的文本。缺少这些内部数据时，尝试 PDF 文字层的浏览器选区。

这些内部字段来自 Zotero 10 阅读器，未来版本改动可能需要适配；插件限制兼容范围为 Zotero 10.0 系列。

## 候选与结果

Unicode 兼容规范化后统一常见英文连字符和弯引号，保留普通词组空格。生成至多三个不同候选：保留词内连字符、只移除断行/软连字符、移除词内连字符。所有候选独立查询同一部当前 MDX，按词目与 HTML 合并相同结果，保留匹配候选标签。

选区原文最大 4096 字符，规范化后最大 256 字符、16 个词。长选区只提供批注工具，不查询词典。不把普通词组无条件连成一个词，不自动补全未选中的半个词，也不发送至网络翻译服务。

## 事件与菜单

在 PDF iframe 内捕获 `pointerdown` / `pointerup`；鼠标松开后等下一个任务，让 Zotero 的选区事件完成。普通指针支持拖选，独立批注工具和修饰键不触发自动查词。已有文字的拖拽操作不触发；新选区或重新拖选后查询，单击没有选区时继续按位置取词。

`src/selection-menu.js` 包装 view 的 `_onSetSelectionPopup` 回调。插件启用、使用合并菜单、普通指针选文字时，将原菜单的显示值设为空，并把该 popup 的选区批注数据交给插件弹窗。保留阅读器的选区、复制动作和独立批注工具，不移除原组件或改写批注存储。

菜单回调与鼠标松开可能先后到达；通过选区签名合并同一次选择的弹窗。关闭、切换词典和退出时，请求序号阻止旧查询覆盖当前弹窗。

## 批注保存

同一弹窗提供 Zotero 的 8 个颜色、`highlight` 和 `underline` 两种动作，没有添加笔记。颜色选择保存为插件偏好；单纯查词或选择颜色不创建批注。

点击动作时，复制阅读器提供的 `text`、`sortIndex`、`pageLabel` 和 `position` 等选区数据，只覆盖 `type` 与 `color`，调用 view 的 `_onAddAnnotation(annotation, false)`。不自行计算高亮矩形或直接写数据库。保存期间/成功后禁用本弹窗的动作按钮，失败时显示错误并恢复按钮。只读状态禁用颜色和动作。

关闭自动划选查词、没有 MDX 或选区超过查词长度时，仍可只显示批注工具。选择“Zotero 自带菜单”时暂停划选自动查询以避免两个菜单同时显示，普通单击查询保留。

## 恢复与清理

设置切回自带菜单或关闭插件功能时恢复原菜单显示。卸载/停止时还原原回调；若另一扩展后续包裹了本插件的回调，则保留其包装，本插件回调改为透传。未来阅读器缺少所需回调时保留原菜单，暂停自动划选弹窗。

退出时清理事件、定时器和资源 URL。词典仍在独立显示区域内，词典 CSS 不影响批注工具或 PDF。

## 本地检查建议

交付前未运行测试或 Zotero 内运行验收。用户安装后可以检查：

1. 普通单击词语与切换词典。
2. 拖选完整 `transfor-` / `mation` 两部分，弹窗应列出 `transfor-mation` 与 `transformation` 的查询情况。
3. 拖选真实带连字符的词，确认保留原写法；两种写法都收录时分别显示。
4. 正向和反向拖选词组，确认空格保留；词组不收录时显示未找到。
5. 选择不同颜色，分别保存高亮和下划线，重新打开文献查看是否保留；长选区或关闭划选查词后，批注工具仍可使用。
6. 设置切回自带菜单、关闭插件功能后，自带菜单恢复；单击查询仍按开关工作。已有批注、独立高亮工具、只读文献和其他批注插件正常。
7. 原有资源显示、编号修复、图片和 MP3/SPX 发音。
