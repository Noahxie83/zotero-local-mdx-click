# 首页与交互示例设计

## 设计判断

面向阅读英文论文、已有本地词典的 Zotero 使用者。采用科研阅读工具的编辑式版面：白色、深蓝正文、清晰的章节序号、少量亮蓝提示。首页重排，插件 UI 与公开配置项保持现状；示例使用插件真实解析与渲染模块。

Design Read：GitHub README + 离线 HTML；视觉变化 5、动效 2、信息密度 5、素材依赖 3、现有 UI 保真 9。变化集中于封面和阅读顺序；无自动播放动画，密集规则移入指南，交互保持插件组件的样式。

## 设计系统

- 颜色：深蓝 `#102b46`，蓝色 `#087bd0`，纸白 `#fcfcf9`，边框 `#dbe5ed`，说明 `#586d7f`。音标使用已有英蓝/美红。
- 字体：页面标题与论文采用 Georgia/宋体，功能和导航采用 Segoe UI/微软雅黑；无远程字体。
- 间距：8px 基准，章节 48px，组件 16/24px。
- 圆角：按钮 6px，阅读示例 12px；展示纸页细边框，悬浮层沿用真实组件阴影。
- 动效：仅 120ms 状态反馈，尊重 reduced-motion。
- 封面负责传达本地词典/论文阅读；示例负责解释点击、断行候选和词典样式；教程负责恢复操作。

## 素材

原创项目文字标识：`assets/wordmark.svg`。封面：`assets/cover.svg`。产品示例：`index.html` 复用 `src/render.js`、`src/native-render.js`、`src/selection-menu.js` 等真实模块。自制示例 MDX/MDD 在构建时生成并嵌入页面，展示文本、CSS、网络示意图和提示音均为本项目原创；不使用用户的商业词典、音频、字体和桌面截图。

页面明确区分浏览器示例和 Zotero 实际批注保存；示例批注按钮只反馈选中类型/颜色，不写入文献库。1.1.3 将原标识的图形用于插件管理器和设置页，独立图标位于 `addon/icons/local-mdx.svg`。
