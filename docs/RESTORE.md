# 恢复设置与回退教程

插件通过 Zotero 阅读器回调显示菜单和保存批注，不替换 Zotero 程序文件，也不修改 MDX/MDD 原文件。下面按想恢复的功能操作。

## 恢复 Zotero 自带划选菜单

1. Zotero → 设置 → **本地 MDX 点击查词**。
2. 将“划选菜单”改成 **Zotero 自带菜单**。
3. 重新划选一段文字，显示 Zotero 原有批注菜单。

此模式暂停划选自动查词以避免两个菜单重叠，**普通单击查词保留**。需要合并菜单时改回“插件查词与批注菜单”。仅取消“划选单词或词组后自动查询”会保留插件的批注工具，不能代替上述菜单切换。

## 暂停全部点击/划选查词与菜单替代

在设置中取消“启用本地查词（点击 / 划选）”，或点击 PDF 工具栏的“本地词典 ✓”按钮关闭。弹窗关闭，自带菜单恢复，词典和资源路径保留；再次启用即可继续使用。

若要停用扩展：工具 → 插件 → 找到“本地 MDX 点击查词” → 停用。停用或卸载会清理监听、弹窗和生成的资源 URL，恢复插件包装的回调。需要重新开始时启用插件并重开 PDF 标签；若同时使用其他菜单插件，按它们自己的设置处理。

## 恢复文字排版 / 原有排版

设置中的“显示方式”：

| 选择 | 作用 |
| --- | --- |
| 简洁文字排版 | 使用插件文字样式，适合不需要原图片/字体或遇到特殊样式时 |
| 词典原有排版 | 读取条目实际引用的 CSS、图片、字体和音频，默认模式 |

切换后重新查询词条。原有排版依赖完整的配套资源，不能靠文字模式还原脚本功能。

## 恢复自动 MDD 关联

1. 先选择需要恢复的当前词典。
2. 点击“恢复自动关联”。
3. 再查询词条。

这会清除**当前词典**手动指定的外置资源目录和额外 MDD 列表，重新采用 MDX 同目录的同名 `.mdd`、数字 `.N.mdd` 和外置资源。其他词典的设置保留，文件不会删除。需要其他名称/目录的 MDD 时再手动添加。

## 恢复词典选择或更新后的文件

重新“选择词典文件夹”或“选择 MDX 文件”，再从下拉框选回所需词典。增加、删除或替换文件后点“刷新词典列表”，重建索引和资源配置。

1.1.2 中新目录读取失败会保留上一份有效选择；成功选择空目录则列表为空，可重新选择原目录恢复。

## 与其他查词插件共存

多个扩展启用相同的点击或划选触发方式时，可能同时显示查询弹窗。选择常用的查询扩展，在其他扩展中关闭重叠的触发方式。各扩展的设置独立；其他高亮工具和已有批注的菜单按各自功能处理。

## 回退到历史插件版本

1. 从 [所有 Releases](https://github.com/Noahxie83/zotero-local-mdx-click/releases) 下载目标版本的 **`.xpi`**，不要把源码 ZIP 当安装包。
2. 工具 → 插件 → 齿轮 → 从文件安装插件，选择旧 XPI。若 Zotero 拒绝覆盖低版本，先卸载本插件，重启后安装目标 XPI。
3. 重启 Zotero并重新打开 PDF，核对版本和词典选择。
4. 如果旧版自动更新回 1.1.2，在插件管理器为该扩展关闭自动更新；重新使用最新版本时恢复自动更新。

| 想回到的功能范围 | 历史版本 |
| --- | --- |
| 最初的本地点击查询/词典切换 | [0.1.0](https://github.com/Noahxie83/zotero-local-mdx-click/releases/tag/v0.1.0) |
| 文字排版优化 | [0.1.2](https://github.com/Noahxie83/zotero-local-mdx-click/releases/tag/v0.1.2) |
| 原有 CSS/MDD 资源与编号修复，尚无划选 | [0.2.1](https://github.com/Noahxie83/zotero-local-mdx-click/releases/tag/v0.2.1) |
| 划选与断行候选，尚无合并批注菜单/内置 Speex | [1.0.0](https://github.com/Noahxie83/zotero-local-mdx-click/releases/tag/v1.0.0) |

历史版本保留各自实现和已知问题，**推荐使用稳定版 1.1.2**。1.1.0 存在批注颜色传递问题，1.1.1 尚未包含 1.1.2 的五项修复；可先调整上述设置恢复所需操作。

Zotero 已保存的高亮和下划线属于文献批注，停用、卸载或回退插件不会删除它们；若需要撤销某条批注，请在 Zotero 中删除该批注。卸载也不会删除本地 MDX/MDD。
