# 0.1.1 词条排版设计

## 目标与依据

使用用户提供的插件与欧陆词典截图作为视觉参考，改进 PDF 查词弹窗。面向阅读英语论文时快速查看双解词条的用户；以词头、音标、词性、义项、例句的阅读顺序组织内容。

这是已有功能上的局部视觉调整：取词触发方式、词典选择、配置保存、关闭操作和文件读取接口保持原有约定。词典内容经安全转换显示，始终不加载词典 CSS、脚本或远程资源。

## 设计取舍

- 视觉变化 3/10：保留弹窗和词典选择入口，重点调整正文层次。
- 动效 1/10：只提供按钮状态，不添加进场动画。
- 信息密度 8/10：减少空行，使连续编号与例句在一屏内更易浏览。
- 素材依赖 1/10：使用本机字体和 CSS，无外部字体、图标或媒体。
- 参考贴近度 8/10：采用截图中的蓝色词头、双色音标、词性横线与斜体例句；保留插件本身的查词弹窗操作。

## 样式约定

- 词头 25px、正文 16px；英文例句 Georgia 16px 斜体，中文翻译 14px 正体。
- 词头蓝色 `#0088d6`；英式音标 `#0068b4`，美式音标 `#b42d36`。
- 词性 / 分类标题使用 `#007ab8` 底色和白字；深色主题另设相应颜色。
- 正文行高 1.5，例句组间距 4px，正文内边距 14px / 19px。
- 弹窗最大 540px × 580px，始终限制在阅读窗口可用范围内，圆角 8px。
- 语法、音标与词性按词典中实际标记分类，不根据排列位置猜测口音。
- 仅保留经过数字范围检查的列表 `start` / `value`，修复义项编号；不复制词典任意属性。
