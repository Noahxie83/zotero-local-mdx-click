# 功能与版本变更

本页汇总 Local MDX 从 0.1.0 到 1.1.2 的功能演进、当前行为，以及对 Zotero 阅读器操作的影响。设置恢复与版本回退步骤见 [复原教程](RESTORE.md)。

## 现在提供的全部功能

| 功能 | 当前行为 | 设置或恢复 |
| --- | --- | --- |
| 点击查词 | 普通指针单击 PDF 英文词语；词内连字符生成两种写法 | 工具栏/设置关闭全部本地查词 |
| 词典目录 | 自选任意目录，列出当前层全部 MDX | 重新选目录/MDX，刷新列表 |
| 多词典 | 弹窗、工具栏和设置均可选择一部当前查询词典 | 下拉框切换，不把多部释义混为一次查询 |
| 划选查询 | 单词或词组；支持反向选区读取、字形分隔和文字层回退 | 可单独关闭自动查询 |
| 断行连字符 | 保留原连字符、拼接断行处、去词内连字符，至多三候选 | 不改 PDF 内容；需选完整两部分 |
| 查询结果 | 标记候选命中，合并重复词条；支持词典内部别名 | 词形依赖词典收录，未加入在线整句翻译 |
| 原有排版 | 按词条实际 HTML/CSS 引用显示，支持不同词典自身样式 | 切换“简洁文字排版” |
| 文字模式 | 英/美音标颜色、词性标题、义项/例句/参照、变形行 | 切回“词典原有排版” |
| MDD 分卷 | 自动关联同名前缀与任意数字分卷，按数字排序 | 可手动多选其他名称/目录的分卷 |
| 外置资源 | CSS、导入 CSS、图片、字体、背景和音频；按引用按需读取 | 指定外置目录或“恢复自动关联” |
| 词条操作 | 发音链接播放、本地词条链接继续查询 | 不运行词典自带脚本 |
| 离线 Speex | 内置 WASM，标准 Ogg/SPX 转 WAV；无需外部程序 | 解码器随唯一安装包提供 |
| 合并菜单 | 普通指针划选时在一个弹窗提供查询、8 色、高亮、下划线 | 改为“Zotero 自带菜单” |
| 批注保存 | 通过 Zotero 接口和跨窗口数据复制保存 | 仅点保存动作时创建；无添加笔记 |
| 清理 | 关闭/切换/停用时撤销资源 URL、取消过期请求、恢复原菜单 | 关闭整个功能或停用扩展 |
| 资源回退 | 单一来源失败继续其他目录/MDD，提示具体路径 | 补资源、刷新；旧选择在失败目录切换后保留 |
| 缓存与边界 | 有界记录/资源索引缓存、定位统计、输出限额、累计音频 30 秒 | 资源配置变化保留未变 MDX 索引 |

所有恢复方法见 [复原教程](RESTORE.md)。完整使用范围见 [使用指南](USER_GUIDE.md)，所有格式与限制仍以代码和指南为准。

## 各版变化

| 版本 | 增加或修复 |
| --- | --- |
| 0.1.0 | 原创本地 MDX 点击查词、自选词典目录、当前词典切换与保存选择 |
| 0.1.1 | 借鉴词典阅读习惯优化文字排版：音标颜色、词性、义项、例句和中英层次 |
| 0.1.2 | 修复重复词性导航、参照项分行、动词变形与音标混排 |
| 0.2.0 | 通用 MDD 与数字分卷、外置 CSS/图片/字体、词典原有排版、资源设置、发音读取与链接 |
| 0.2.1 | 修复原有列表重复编号、备用字体缺失误报，补发音格式提示 |
| 1.0.0 | PDF 划选单词/词组、断行词候选、独立查询与重复合并、选区长度限制 |
| 1.1.0 | 合并查词与批注菜单、8 色/高亮/下划线、自带菜单恢复、内置 Speex 解码器；去除添加笔记 |
| 1.1.1 | 修复 `Missing 'color' property`，完整批注数据复制到 Zotero 阅读器窗口 |
| 1.1.2 | 修复 LZO 精确边界、合法别名、失败目录切换、资源来源错误回退、Speex 累计时长；普通音频单次读取、MDD 定位/缺失缓存与统计、独立资源失效；33 项回归与独立 Zotero 保存验收 |

各版对应的源代码快照、安装包与原说明见 [Releases](https://github.com/Noahxie83/zotero-local-mdx-click/releases)。历史快照保持原样，详细当时记录见 [发布说明](../RELEASE_NOTES.md)；1.1.2 验证证据见 [审查整改](REVIEW_FIXES_1.1.2.md)。
